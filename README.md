# My Communication Board

A static, computer-based teaching prototype using the supplied 11-column, 7-row home-board image. It is not the Proloquo2Go app.

## Try it now
1. Extract this ZIP.
2. Keep index.html, app.js, and home-board.png together.
3. Open index.html in your browser.
4. Click Voice settings, select a computer voice, and press Test voice.
5. Click a word to speak it and add it to the message. Speak message reads the entire message.

No installation, API key, or build command is required. Audio uses your browser's speech engine and available computer voices. Some voices may need an internet connection. Share computer audio when presenting virtually.

## GitHub repository contents
Upload index.html, app.js, home-board.png, .nojekyll, and this README to the root of a new repository named aac-home-board. This package does not create the repository or publish a website. The supplied symbol image is not granted an open-source license by this package.

## What is implemented
63 speaking word buttons, sentence builder, undo, clear, stop voice, speaking speed, voice selection, full screen, keyboard-accessible buttons, and original home-page positions. Settings are stored in this browser; messages are not saved.

## Folder pages
14 folder buttons open an explicit page-not-added message. Screenshots of those pages are needed to reproduce their contents accurately. No folder vocabulary has been invented.

## Validation
JavaScript syntax passed. Browser checks confirmed word selections and sentence building. The test browser had no working speech voice, so audible output must be checked on your computer.
